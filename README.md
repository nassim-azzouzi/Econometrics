Financial Econometrics: CAC 40 Analysis
This repository contains a quantitative analysis of the French stock market index (CAC 40) using Python. This project was conducted for the M1 Financial Economics program at EDHEC Business School.

Project Overview
The analysis explores the historical behavior of the CAC 40 over a 30-year period (1994-2024) and is divided into two core sections:

Stylized Facts of Financial Returns: An empirical verification of the universal characteristics of the CAC 40 returns, including Stationarity, Aggregational Gaussianity, Volatility Clustering, and the Leverage Effect.

Asset Pricing Models: A comparative OLS regression analysis testing the CAPM versus the Fama-French 3-Factor Model on monthly excess returns.
